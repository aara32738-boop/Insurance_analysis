# Лабораторная работа 1. Предварительная обработка и визуализация данных

## Описание набора данных

Набор данных **Medical Cost Personal Datasets** (страховые расходы на медицинское обслуживание) взят с [Kaggle](https://www.kaggle.com/datasets/mirichoi0218/insurance).

- **Файл:** `insurance.csv`
- **Количество наблюдений:** 1338
- **Количество признаков:** 7

### Состав показателей и типы данных

| Признак    | Описание                                      | Тип данных | Уникальные значения / диапазон      |
|------------|-----------------------------------------------|------------|-------------------------------------|
| `age`      | Возраст застрахованного                       | int64      | 18–64                               |
| `sex`      | Пол (`female` / `male`)                       | object     | 2 категории                         |
| `bmi`      | Индекс массы тела (Body Mass Index)           | float64    | 15.96–53.13                         |
| `children` | Количество детей, покрываемых страховкой      | int64      | 0–5                                 |
| `smoker`   | Статус курения (`yes` / `no`)                 | object     | 2 категории                         |
| `region`   | Регион проживания в США                       | object     | northeast, northwest, southeast, southwest |
| `charges`  | Медицинские расходы, выставленные страховкой  | float64    | 1121.87–63770.43                    |

Пропущенных значений в датасете **нет**.

## Подключаемые библиотеки

- `pandas` — загрузка, просмотр и предобработка данных
- `matplotlib.pyplot` — построение графиков
- `seaborn` — статистические визуализации и тепловые карты

## Методы предобработки данных

1. **Проверка типов данных**  
   Использовался метод `DataFrame.info()` для анализа типов столбцов.

2. **Обнаружение пропусков**  
   Применялся метод `DataFrame.isnull().sum()` — пропущенных значений не обнаружено.

3. **Преобразование категориальных признаков**
   - Бинарные признаки `sex` и `smoker` преобразованы в числовые с помощью метода `.map()`:
     - `sex`: `female` → 0, `male` → 1
     - `smoker`: `no` → 0, `yes` → 1
   - Многоклассовый признак `region` преобразован методом **One-Hot Encoding** (`pd.get_dummies(..., drop_first=True)`), чтобы избежать мультиколлинеарности.

## Визуализации

В ноутбуке построены следующие графики:

1. Гистограмма распределения страховых расходов (`charges`) с кривой плотности (KDE).
2. График влияния курения на величину расходов.
3. Тепловая карта корреляции всех числовых признаков после предобработки.
